03 / SYSTEM MATCHING

アンプ・スピーカー相性診断

必要な音圧に対してアンプの出力余裕を計算し、負荷インピーダンスと帯域別データの取得状況を別々に示します。すべて架空のデモ製品です。音質を主観的に点数化しません。

簡易計算モデル
SPL ≈ 感度(dB/1W/1m) + 10 log10(P/W) − 20 log10(d/1m) + ステレオ補正
必要電力は、この式を逆算して求めます。自由音場の距離減衰を仮定した概算であり、近接音場・室内反射・スピーカー指向性・熱圧縮などは再現しません。目標ピーク音圧に安全余裕を追加して必要電力を判定します。アンプの定格出力は適切な負荷での連続出力値というデモ上の仮定です。
帯域の相性：周波数別インピーダンス曲線、位相角、アンプ出力インピーダンス、負荷別の周波数応答・歪み測定が揃うまで判定を保留します。架空の曲線で音色を推定しません。
04 / METHODOLOGY

評価方法と計算条件

以下は試作版の暫定方式です。業界標準や実証済みの心理測定尺度であると主張するものではありません。将来は測定規格や再現性検証に合わせて更新します。

参考適合度の計算方法
各指標を事前に定義した固定基準範囲で 0〜100 に正規化。価格は安いほど、出力とS/Nは高いほど、THD+Nは低いほど高評価。THD+Nは対数尺度を使用します。
Score = Σ (有効な重み × 指標スコア) / Σ (有効な重み)
Coverage = Σ (測定値が存在する指標の重み) / Σ (全指標の重み)
欠測は分母から除くものの、Coverageを必ず併記。Coverageが70%未満なら参考適合度を表示せず「比較保留」とします。出典・第三者測定の有無は得点と分離し、透明性指標として表示します。
固定正規化範囲（このデモのアンプ用）
価格：20,000〜100,000円 ／ 8Ω出力：20〜160W/ch ／ THD+N：0.1〜0.0001%（対数尺度） ／ S/N：70〜120dB
出力・歪み・S/Nは測定条件を揃える必要があります。デモでは説明のため同一条件と仮定しています。実サイトでは周波数・負荷・帯域・出力レベル等が不一致なら直接比較を許しません。
価格と音響性能の総合適合度は、重み付けに依存する主観的な意思決定支援値です。サイト独自の客観的な「音質スコア」とは呼びません。
05 / PRINCIPLES

データに関する6つの原則

01｜実測と公称を分ける

メーカー値は独立測定の代用にしない。同一の指標でも証拠の種類と取得日を保存。

02｜欠測を満点にしない

不明値は不明値として保持。比較可能範囲を提示し、不完全な序列を明示する。

03｜機能はユーザーが指定

必要のない希少機能は比較上の加点対象にしない。必須条件は利用者が選ぶ。

04｜すべての式を公開

基準範囲、換算式、重み、欠測処理をドキュメント化する。

05｜条件を揃えて比較

測定負荷、信号レベル、測定帯域を記録し、条件が異なる値の比較を制限する。

06｜改訂履歴を残す

出典の変更、測定訂正、価格変更、評価方式の改訂履歴を追跡可能にする。
