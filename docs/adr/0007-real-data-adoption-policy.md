# ADR-0007 — 実在製品データの採用ポリシー(草案)

Status: **draft / proposed** — PL レビュー待ち。本 ADR が承認されるまで、実在データは投入せず、評価ロジックへの接続も行わない。

## 文脈

Phase 1–2 は架空データで方法論と品質ゲートを整備した。Phase 3 で実在製品(SMSL AO300 PRO、KEF LS50 Meta)を扱うにあたり、「どの数値を、どの条件で、どの証拠種別として採用し、何を比較・表示してよいか」を決める必要がある。これは測定論上の判断を含むため PL の承認を要する。

## 代替案(採用しない理由)

- 公称値と第三者測定の**平均**: 条件・証拠種別が異なる値の合成であり却下。
- 第三者測定を常に公称値で**上書き**: 情報が失われ、差分の表示ができないため却下。
- 感度を一律 1 W/1 m へ換算して保存: 元の基準が失われ、換算近似が追跡できないため却下(換算は表示時・計算時に系譜つきで行う)。

## 結果

- 採用されれば DATA_GAP_ANALYSIS.md の G1–G8 拡張と、INGESTION_DESIGN.md の手順を実装する。
- 本 ADR は評価**式・正規化範囲・閾値**を変更せず、`METHODOLOGY_VERSION` の定義上はバージョン据え置きである。ただし P3・P8・P9 は**投影・比較規則(ADR-0004 §5)の解釈変更**であり、AGENTS の「scientific interpretation の変更は承認要」に該当する。承認時は ADR-0004 に改訂注記を加える。
