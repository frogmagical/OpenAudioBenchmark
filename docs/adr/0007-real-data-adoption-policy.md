## 文脈

Phase 1–2 は架空データで方法論と品質ゲートを整備した。Phase 3 で実在製品(SMSL AO300 PRO、KEF LS50 Meta)を扱うにあたり、「どの数値を、どの条件で、どの証拠種別として採用し、何を比較・表示してよいか」を決める必要がある。これは測定論上の判断を含むため PL の承認を要する。

### P9 に伴う方法論バージョンの整合(設計のみ)

- 採点適格性の導入は投影規則の変更であり、`METHODOLOGY_VERSION` を `0.6.0-demo` に上げる(式・正規化範囲・閾値は不変だが、カバレッジの分母定義が「全指標の重み」から「採点適格な指標の重み」へ変わるため、結果が変わり得る)。
- **採点入力の経路**: 現行 `calculateUtility(values: MetricValues, weights)` は `number | null` しか受け取らず、`null` が欠測か不適格か判別できない。`MetricValues` を `{ value: number | null; eligibility: 'eligible' | 'ineligible' | 'missing' }` の 3 状態に拡張する(または第 3 引数で適格性マップを渡す)シグネチャ変更が必要。`toMetricValues` は投影の `eligibility` をそのまま渡す。
- **分母の解釈(PL 再レビューで確認)**: 「70 % カバレッジには採点適格な指標だけを算入」を本 ADR は「分母も適格指標の重みに限定」と解釈した。帰結例: 4 指標中 3 つが不適格・1 つが適格なら coverage = 1.0 で `scored` になる(不適格指標は分母に現れない)。代替解釈「分母は従来どおり全指標、不適格は分子に入れない(= 欠測と同じ扱い)」では同例の coverage は 25 % → `pending`。**どちらを意図するか PL の確認を要する**。
- 架空デモデータは全測定の条件が同一仮定で記録されており、必須条件(THD+N の出力レベル、S/N の重み付け)が未記録 → 新規則では**デモの THD+N・S/N が不適格**になり、デモの採点結果が変わる。選択肢: (a) デモ条件に `outputLevel` / `weighting` を明示的に「demo-assumed」として記録し適格にする、(b) デモの挙動変化を受け入れ UI 文言を更新する。**PL/PM 判断事項(D-18)**。
- 状態の 3 区分: `missing`(値なし)/ `ineligible`(値あり・条件未記録または estimated、採点対象外)/ `eligible`(採点入力)。`UtilityResult` に `ineligibleMetrics` を追加し、JSON 出力の `computed` にも載せる。

## 代替案(採用しない理由)

- 公称値と第三者測定の**平均**: 条件・証拠種別が異なる値の合成であり却下。
- 第三者測定を常に公称値で**上書き**: 情報が失われ、差分の表示ができないため却下。
- 感度を一律 1 W/1 m へ換算して保存: 元の基準が失われ、換算近似が追跡できないため却下(換算は表示時・計算時に系譜つきで行う)。

## 結果

- 承認・条件付き承認分は DATA_GAP_ANALYSIS.md の G1–G8 拡張、採点適格性(P9)、INGESTION_DESIGN.md の手順として**別 PR で実装**する(本工程では実装しない)。P3 は実装しない。P7 は PM/法務判断後。
- 評価式・正規化範囲・閾値は変更しない。ただし P9 は **Coverage の分母定義**(`scoring.ts` ヘッダの式 Σ weight_i over all i)を変えるため、`methodology.ts` の規則(式・範囲・閾値の変更でバンプ)に従い `METHODOLOGY_VERSION` を **`0.6.0-demo`**(架空デモ継続中は `-demo` 接尾辞を維持)へ上げる(D-18)。P1・P8・P9 は投影・比較規則(ADR-0004 §5)の解釈変更でもあり、承認時は ADR-0004 に改訂注記を加える。P3 は未承認で実装しない。
