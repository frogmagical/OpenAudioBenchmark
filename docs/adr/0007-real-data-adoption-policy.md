# ADR-0007 — 実在製品データの採用ポリシー(草案・PL 技術レビュー済み、PM 承認前)

Status: **PL 技術レビュー済み(2026-11-08、修正条件付き受入)** — 各提案の判定は下表の「PL 判定」列のとおり。PL の受入は PM のマージ承認ではない。本 ADR に基づく実装(採点適格性、`MeasurementReference` 等)は**本工程では行わない**。法的判断(P7)は PM/法務に保留。

PL レビューの所在: https://github.com/frogmagical/OpenAudioBenchmark/pull/9 (コメント 2026-11-08T10:39:55Z)、運用ルール: https://github.com/frogmagical/OpenAudioBenchmark/issues/10

## 文脈

Phase 1–2 は架空データで方法論と品質ゲートを整備した。Phase 3 で実在製品(SMSL AO300 PRO、KEF LS50 Meta)を扱うにあたり、「どの数値を、どの条件で、どの証拠種別として採用し、何を比較・表示してよいか」を決める必要がある。これは測定論上の判断を含むため PL の承認を要する。

### P9 に伴う方法論バージョンの整合(設計のみ)

- 採点適格性の導入は方法論の式そのものの変更ではなく**入力の適格性判定の追加**だが、結果と解釈が変わるため、実装時に `METHODOLOGY_VERSION` を更新する(`0.6.0-demo` が候補)。Coverage の式(分母 = 全 4 採点指標の重み)と 70 % 閾値は維持。本 docs PR では現行版もコードも変更しない。
- **採点入力の経路**: 現行 `calculateUtility(values: MetricValues, weights)` は `number | null` しか受け取らず、`null` が欠測か不適格か判別できない。`MetricValues` を `{ value: number | null; eligibility: 'eligible' | 'ineligible' | 'missing' }` の 3 状態に拡張する(または第 3 引数で適格性マップを渡す)シグネチャ変更が必要。`toMetricValues` は投影の `eligibility` をそのまま渡す。
- **分母の解釈(PL 確定、2026-11-08 再レビュー)**: 「採点適格な指標だけを算入」は**分子**の意味。分母は全 4 採点指標(または事前に固定された全採点対象指標)の重み。`ineligible` と `missing` は区別して記録・表示するが、いずれも分子に入れない。例: 等重み 4 指標で適格 1 / 不適格 3 → 25 % → 判定保留。
- 架空デモデータは必須条件(THD+N の出力レベル、S/N の重み付け)が未記録のため、新規則では**デモの THD+N・S/N が不適格**になり採点結果が変わる。**PL 判断確定(D-18)**: v0.4 baseline と既存架空デモの不変性を維持し、スコア維持のために `demo-assumed` 等で条件を機械的に補ってはならない。新規デモ用フィクスチャが必要なら架空の前提を明示して別バージョンで作成する。既存デモの評価結果が変わる場合は差分と根拠を提示し、**別 PR で明示的に承認**を受ける。
- 状態の 3 区分: `missing`(値なし)/ `ineligible`(値あり・条件未記録または `estimated`、採点対象外)/ `eligible`(採点入力)。`UtilityResult` に `ineligibleMetrics` を追加し、JSON 出力の `computed` にも載せる。分母は従来どおり `totalWeight`(全 4 指標)。

## 代替案(採用しない理由)

- 公称値と第三者測定の**平均**: 条件・証拠種別が異なる値の合成であり却下。
- 第三者測定を常に公称値で**上書き**: 情報が失われ、差分の表示ができないため却下。
- 感度を一律 1 W/1 m へ換算して保存: 元の基準が失われ、換算近似が追跡できないため却下(換算は表示時・計算時に系譜つきで行う)。

## 結果

- 承認分は DATA_GAP_ANALYSIS.md の G1–G9 拡張、採点適格性(P9)、INGESTION_DESIGN.md の手順として**別 PR で実装**する(本工程では実装しない)。P3 は「比較条件としての保留維持」を実装し、採点適格性の必須条件には一律追加しない。P7 は PM/法務判断後。
- 評価式・正規化範囲・閾値・Coverage の分母(全 4 採点指標の重み)は変更しない。P9 は入力の適格性判定の追加であり、結果と解釈が変わるため実装時に `METHODOLOGY_VERSION` を更新する(`0.6.0-demo` が候補、架空デモ継続中は `-demo` 接尾辞を維持)。P1・P8・P9 は投影・比較規則(ADR-0004 §5)の解釈変更でもあり、承認時は ADR-0004 に改訂注記を加える。本 docs PR では現行版・コードを変更しない。
