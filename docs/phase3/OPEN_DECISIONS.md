# Phase 3 — PL 判断を要する事項

## 結論

実在データ導入の前に、次の判断が必要である。D-01〜D-08・D-13・D-17 は測定論・採用ポリシー(ADR-0007 草案に対応)、D-09〜D-12・D-14〜D-16 はモデル・運用・利用許諾上の決定。いずれも AI 側で確定せず、PL レビューの結果を ADR に反映してから実装する。

## 本工程で確定させないこと(PL 指示による禁止事項)

- 参考価格の自動選択・採点接続(ADR-0005 O4)。
- 最小インピーダンス等からの負荷難易度スコア、アンプ適合性・安全性の断定(ADR-0006)。
- ライセンス未確認データの複製・再配布、実データの投入、デプロイ。
